# Best Coder Dark

A premium dark theme crafted for developers who live in the code. Deep contrast, vibrant syntax, easy on the eyes.

## Features

- Deep, rich dark background that reduces eye strain
- Vibrant, carefully chosen syntax colors for maximum readability
- Semantic highlighting support for smarter colorization
- Optimized for JavaScript, TypeScript, Python, HTML, CSS, JSON, and more

## Color Palette

| Element        | Color                                                              |
| -------------- | ------------------------------------------------------------------ |
| Background     | `#151a22`                                                          |
| Foreground     | `#e2e6f0`                                                          |
| Functions      | `#82d9a0`                                                          |
| Strings        | `#ecc48d`                                                          |
| Keywords       | `#c792ea`                                                          |
| Types/Classes  | `#89ddff`                                                          |
| Constants      | `#f78c6c`                                                          |
| Properties     | `#c3e88d`                                                          |
| Parameters     | `#e0cea8`                                                          |

## Installation

1. Open **Extensions** in VS Code (`Ctrl+Shift+X`)
2. Search for **Best Coder Dark**
3. Click **Install**
4. Go to `File > Preferences > Color Theme` and select **Best Coder Dark**
